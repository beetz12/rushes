# Native encoder startup observation

At the first existing ten-second encoder-start timeout, freeze the selected
role, same-Window time and elapsed duration, per-role start-call/return/event,
error and nonempty chunk counters, current recorder states, held track states
and a nonfatal read-only audio transport status. Do not manufacture an audio
failure, consume more media or add a timer, request or clock conversion.

After the existing owned release, publish that frozen detail through the
optional warning argument before native Stop/finalization. A refusing warning
consumer is retained as a secondary event and cannot suppress the original
startup rejection or prevent finalization. Keep the original timer and message.
Generated diagnostics serialize a separate strictly bounded encoder-timeout
row, so the existing warning's512/raw4096 limits remain. Ordinary UI consumers
keep their string. Reuse existing observers only; missing values remain absent.

Before a new Mac native profiler experiment, the isolated workflow may inspect
its documented CLI/template capability outside capture. Retain only fixed
status fields and whether System Trace is listed. Do not publish raw tool
output, infer profiling permission, or invent an OS thread-state/timebase parser.
Existing source, timing, integrity, retirement and publication gates remain.
