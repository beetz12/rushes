# Startup must retain terminal ownership

A composition/source failure can begin finalization while native start events are still pending. Chrome can deliver late start events as part of Stop. Those events must not let the original start operation save another active checkpoint or return success after its take has begun terminal cleanup.

Recheck terminal ownership after the native-start event join and after the initial checkpoint await. Retain the first failure message; otherwise reject a take canceled/stopped during startup. Recheck after arming the take deadline too: arming can hand ownership to automatic Stop synchronously. Skip startup cleanup only when the existing Stop/Cancel promise actually exists, join it, and retain a secondary owner error as the rejection cause. A pause remains allowed and is not a terminal transition. Keep the original startup/storage/finalization deadlines, persistence ownership, native events, media streams and PCM model unchanged. This is a lifecycle correctness control, not a repair claim for the hosted source gaps or Windows encoder stall.

Verify the actual capture module with controlled source/compositor failure and delayed native events, plus failure/cancel during a held checkpoint. Preserve ordinary start and pause during the same checkpoint as positive controls. These transport doubles do not encode media; real capture gates and fresh same-source qualification remain mandatory.

On an already fatal take, request shutdown of the owned sources and composition producer before entering synchronous native Stop. Healthy Stop keeps its existing verified drain. A producer shutdown exception stays secondary and must not prevent native Stop or its acknowledgement join. Ended tracks, a termination request or inactive recorder state are not stop acknowledgements: still join every started recorder's actual stop event and preserve previously acknowledged bytes. The Windows wrapper delay motivates measuring this order; the change is not proof of that delay's cause or of a repaired startup pipeline.
