# Original transcription and local automation design

This design follows the approved PLAN rather than reference implementations. No reference repository source was opened or copied.

SpeechAnalyzer reads microphone media, falling back to system audio only when no microphone file exists. SpeechTranscriber supplies finalized text and real audio-time attributes. Missing or unsupported assets produce structured errors; optional first-use Apple model installation is disclosed and explicitly enabled by the caller. Speech is processed on-device. No transcript is fabricated when recognition fails. Audio-time attributes retain the source timeline; a text run containing several tokens divides that run's actual time range conservatively and identifies that timing as proportional.

Caption construction sorts valid words by time, rejects malformed ranges, ignores words wholly inside measured silence, and starts a fresh cue on a gap of at least 900 ms. A cue never exceeds 4000 ms or 42 Unicode characters. An unusually long word is split only for subtitle display while preserving the transcript word record. Adjacent very short cues merge only if duration, gap and character limits still hold. Cue starts and ends strictly advance; conflicting source words are retained in the transcript, with display times clamped for readable captions.

Edit suggestions are source-time removed ranges, without altering source media or word records. Selected words and hesitation tokens define candidate cuts. Every kept word receives 70 ms protected breathing space. Cut ranges are subtracted against all protected intervals before merging. Silence proposals remove only the middle of gaps over 1100 ms, retaining 350 ms on either side. The same planner accepts measured level-based silent intervals.

Metadata uses an evenly sampled whole-recording transcript and Apple's explicit on-device SystemLanguageModel, only when available. An extractive deterministic fallback identifies itself and keeps only words present in the transcript. Chapter starts are grounded in source words, start at zero and span the recording. User-authored metadata is validated and saved atomically in a sidecar.

Diagnostics writes caller-supplied textual state into a local zip, after removing home-folder paths, URL queries and secrets. It does not collect audio or transcripts automatically. A strict URL parser permits record, stop, pause and resume only, rejects duplicate or unexpected arguments, and converts them to existing commands. The loopback MCP endpoint validates bearer token, loopback Host and browser Origin before JSON-RPC handling. Mutating commands require a separate switch; read-only commands share the existing engine dispatcher. HTTP body and header sizes are bounded and malformed or ambiguous framing is rejected.

The original level scanner reads decoded PCM in 50 ms windows. It computes RMS across channels, takes the 95th-percentile window as the speech reference, and marks windows 25 dB quieter as silence. An entirely quiet track is one silent interval. Non-finite samples are rejected. Runs of quiet windows become source-time intervals, used both to avoid silence-contained caption words and to propose the middle-gap cuts; protected kept-word regions still take priority.

## Native integration contract

`TranscriptCommands.handle(request:packageURL:)` returns JSONValue for `transcript.get`, `transcript.run` (`locale`, `allowAssetDownload=false`), `transcript.correct` (`wordId`, `text`), `transcript.edit-plan` (`wordIds`, `removeFillers`, `removeSilence`, `levelSilence`), and `captions.export` (`format`, optional `outputPath`). The `transcribe` alias runs and stores all four formats; a CLI asking for a particular format then exports it. Edit plans return `{sourceStartMs,sourceEndMs,reason,wordIds}` without applying changes. Word source is `asr` or `user`; `timing` explicitly identifies any proportional timing within an Apple audio-time run.

`MetadataCommands.handle` returns `{title,summary,chapters:[{startMs,title}],engine,warning?}` for `meta.get`, `meta.generate`, and `meta.set` (partial fields). `chapters.export` returns text or writes `outputPath`. Thumbnails belong to the export module. Sidecars remain separate from unchanged masters. Root updates the library index/metadata and schedules transcription after stop; these functions do not own record lifecycle or upload jobs.

`AutomationDispatcher` receives the actual shared command table as MCPTool values and an async ControlRequest handler. `LoopbackMCPServer.start()` returns its actual ephemeral or configured port, only bound to 127.0.0.1. The engine owns enable state, private token persistence, and `setAllowMutations`; mutations default off. `RushURLRoute.parse` gives an existing ControlRequest. `DiagnosticsBundle.write(outputURL:entries:)` accepts bounded text entries only, with safe filenames and a local ZIP destination.

`TeleprompterMatcher` provides forward-only matching with an eight-word lookahead; wiring microphone buffers to live recognition and displaying the excluded overlay belongs to the capture/shell integration. This module does not claim teleprompter recording QA or camera-blur support.
