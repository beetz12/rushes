# Independent M1 recording measurements

This slice owns only `browser/test/matrix*.mjs` and this evidence record. Production
capture files, provider accounts, the shared GUI and Beads were read-only. Root
owns final acceptance, Windows CI and physical picker/minimization checks.

The matrix launches a separate installed stable Chrome process with a new local
profile. Its headless CDP endpoint belongs only to that process. No authenticated
profile, real camera, microphone, screen permission or vendor service is used.
Chrome is spawned directly rather than with Playwright's flags that disable
background timer, renderer or occlusion throttling. The exact flags, runtime,
source revision and source/fixture hashes are saved with each result.

Native Chrome fake-camera input is generated 1280×720, 30 fps MJPEG from a Y4M loop. The
representative input uses moving detailed tiles; `RUSHES_M1_ENTROPY=1` selects
pixel-noise stress. Each native frame carries a sixteen-bit phase ordinal, increasing
every fifteen frames. A frame-fed worker reads that ordinal and sends it through
a transferred port directly to a real AudioWorklet. Two tone frequencies encode
the complete ordinal, without Window media timers or a repeated binary-pulse match.
Chrome documents [native Y4M and MJPEG test-device input](https://chromium.googlesource.com/chromium/src/media/+/master/capture/video/file_video_capture_device.h).
Native fake-WAV input on this Mac supplied digital silence in the retained early
prototype even though FFmpeg decoded the input WAV with a nonzero level. The
AudioWorklet substitute proves the audio recording path, not a physical microphone.

The production frame-fed worker, separate MediaRecorders and OPFS journal run
unchanged. Independent processors monitor native input and composed output counts,
timestamps, per-second buckets and stale tails. An instrumented recorder/store
measures actual chunk sizes, outstanding bytes, serialized appends and commit
latency. RSS is the sum of the isolated Chrome process tree's resident sets, which
can double-count shared pages; instrumentation adds four monitoring processors
and a separate source-anchor observer.
It is not a measurement of unique/private memory or an uninstrumented product.
The native MJPEG source is memory-mapped by Chrome; its file footprint is included
in process RSS. The long source is 630 seconds so its numbered markers do not loop
during the 600-second take plus pauses/setup. Its actual file size is recorded with
the proof rather than attributed to product buffering.

After normal Stop, the fixture downloads all five tracks. FFprobe decodes video
frames for dimensions, duration, cadence and gaps. FFmpeg independently decodes
the optical ordinal barcode and dual-frequency audio PCM for beginning/middle/end
calibration. Goertzel power measurements recover exact audio ordinals; each edge
requires the preceding and following numbered phase in a fixed bracket. The initial
audio/video ordinals must agree, and IDs do not repeat during the supported take.
There is no search for a convenient same-polarity pulse. Manifest
start offsets are applied; the 100 ms drift and 250 ms gap/duration gates remain
unchanged. Source timestamps, frame counts, all decoded gaps and audio/video duration
remain separate gates. The earlier binary prototype only established nearest-phase
agreement and is explicitly not absolute-sync acceptance.

Abrupt recovery kills the whole owned browser process tree, reopens the same local
origin/profile, and compares every acknowledged primary and closed-backup chunk's
byte length and SHA-256. Device methods throw if recovery attempts to reacquire
media. The backup handle is a second OPFS directory: this tests closed writes across
process death, not an OS-selected external folder. Tail loss is measured from
effective elapsed time minus the reopened durable checkpoint; no zero-loss or
interrupted-file playability promise is inferred.

Storage failure probes reduce the real origin quota through isolated Chrome's
Storage API, and separately inject a rejected Blob write at the actual OPFS
writable-stream method. Both must end interrupted while retaining prior chunks.
The injected write error is a fault model, not evidence of a physical disk failure.

## Reproduction

Use Node 22.22.0 and the package's locked dependencies. FFmpeg and FFprobe must be
on PATH, or supplied through `RUSHES_FFMPEG`/`RUSHES_FFPROBE`. No npm dependency was
added. `RUSHES_CAPTURE_BROWSER` defaults to `chrome`; a specific installed binary
can be selected with `RUSHES_CAPTURE_BROWSER_EXECUTABLE`.

```
npm ci --prefix browser
node browser/test/matrix.mjs
RUSHES_M1_LONG=1 RUSHES_M1_PROOF=<private-new-directory> node browser/test/matrix.mjs
RUSHES_M1_ENTROPY=1 RUSHES_M1_PROOF=<private-new-directory> node browser/test/matrix.mjs
```

Default is an eight-second smoke with five pauses. Long mode exercises the
production 600-second limit, five one-second pauses, five minutes offline and
virtual-page switching. The current fixture plays a muted composed preview, matching
a recorder UI. Every proof directory contains `metrics.json`, synthetic
source media, finalized separate tracks and the isolated profile for read-back.
